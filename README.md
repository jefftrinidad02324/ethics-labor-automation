# Ethics of Labor Automation — Educational Website

An original, light-themed interactive website based on Jeff Trinidad's MO-SS036 Milestone 1 and 2 research. Includes the completed presentation video, graphs, figures, sources, ethical case examples, proposed pilot, and five-question scored quiz.

## Publish with GitHub Pages
1. Extract the ZIP file to a folder.
2. In GitHub Desktop choose **File → Add local repository**. If GitHub Desktop says this is not a repository, choose **Create a repository here** and select this folder.
3. Commit the files, then click **Publish repository** (make it Public for GitHub Pages on a standard free account).
4. On github.com, open the repository → **Settings → Pages** → **Deploy from a branch** → branch `main`, folder `/ (root)` → **Save**.
5. Open the GitHub Pages URL shown in Settings → Pages after deployment.

## Video
The provided MP4 is included at `assets/presentation.mp4` (approximately 36 MB). GitHub recommends files below 50 MB and blocks ordinary Git uploads over 100 MB. This MP4 should fit normal Git upload limits. If playback stalls on a slow connection, consider hosting a copy as an unlisted YouTube video and replacing the `<video>` element with its official embed iframe.

## Integrity
Research statistics come from the supplied academic papers and their cited sources. Proposed pilot costs and weighted option scores are author assumptions, not completed outcomes. This website does not reproduce restricted academic templates.
